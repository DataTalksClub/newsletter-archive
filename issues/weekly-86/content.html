Project of the Week

Want to learn by doing? This week, we start "Project of the Week".

It's like a study group but with focus on building things and learning by doing. Every day we have a set of tasks. We finish them together and hold each other accountable.

The first project that we'll do together is creating a frontend for an ML model with Streamlit.
