Project of the Week: DIY Python package
Are you tired of learning data science theory without any practice?

Project of the week is your chance to get hands-on experience and practice every day!

Starting from August 30, we will learn to do the DIY Python package.
  1. Come up with a project idea
  2. Create a virtual environment for developing your Python package
  3. Add functions to your package
  4. Add docstrings to all of the functions
  5. Create a README for your package
  6. Build your Python package
  7. Continue improving your package and polishing the documentation
Special kudos to Liliana Badillo, who organized and created content for the project!

Join us to practice together, build your network, and enjoy the learning process!

  • Performing transformations, both in Python and with dbt
