Your AI Agent Can Look Accurate and Still Be Broken
On March 24 at 5 PM CET, we're running a hands-on workshop on evaluating MCP-powered agents beyond final-answer scoring with Agent GPA.

Together, we'll:
  • Build an agent connected to Snowflake MCP
  • Evaluate it with TruLens
  • Identify failures in planning, tool selection, and execution
  • Improve the agent by rewriting MCP tool definitions
  • Rebuild and compare both versions using traces and evaluation data
You'll leave with a practical framework for analyzing an agent's goals, plans, tool usage, and execution, and for improving agent quality in a more systematic way.
