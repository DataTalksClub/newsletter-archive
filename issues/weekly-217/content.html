Data Engineering Zoomcamp

The due date for the final project is in one week, on April 1.

You need to build a dashboard with two components by following these steps:

  1. Choose a dataset
  2. Develop a pipeline to process and upload it to a data lake.
  3. Create a pipeline to transfer data from the lake to a warehouse.
  4. Transform the data for the dashboard.
  5. Finally, build a dashboard to visualize the data.
Decide if your pipeline will be stream (real-time) or batch (set intervals).
