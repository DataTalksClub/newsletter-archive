Project of the Week: Getting Started with Rust
From 17th to 22nd May, we will be studying Rust. By the end of the week, you will have learned the fundamentals of Rust and have your first steps in building awesome Rust solutions!

We will be using an open Rust book.

Plan for this week
  1. Introduction to Rust, your first "Hello world!" exercise
  2. Common Programming Concepts in Rust
  3. Functions and Control Flow
  4. Memory Management, Heap & Stack and Ownership
  5. Using Structs to Structure Related Data
  6. Additional topics
Special kudos to Antonis Stellas, who organized and created content for the project!

Join us to practice together, build your network and enjoy the learning process!
