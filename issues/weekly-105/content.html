Podcast
We uploaded a new podcast episode recently: Data-Centric AI by Marysia Winkels:
  • Marysia has experience with the data-centric approach to AI, which focuses on changing the data rather than the model
  • The data-centric approach involves iterating on both the model and the data and requires careful data selection and improvement
  • Tools such as data augmentation and visualization can be used to improve data for the data-centric approach
  • It is important to consider the ethical implications and ensure that the data is representative and unbiased
  • Marysia co-organizes PyData Amsterdam and PyData Global, which focus on data science and data analytics and are open to all programming languages
  • Marysia joined the PyData Amsterdam committee in 2018 and PyData is an organization that supports open source packages in the data science ecosystem
  • PyData is focused on data science and data analytics, while PyCon is a broader conference for everything Python
  • "Shadow Mode" deployment and user feedback can be used to improve model performance
  • It may be more efficient to use tools or models to automate data cleaning and editing, rather than doing it manually
  • Insufficient or poor quality data can hinder the ability to complete a project.
