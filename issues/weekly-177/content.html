New Workshop: Implement a Search Engine

We shared a recording of the workshop where Alexey Grigorev presented a hands-on tutorial on constructing a search engine from scratch focusing on text and vector search methods.

Alexey covered:

  • Setting up the environment and installing libraries
  • Implementing text search with scikit-learn
  • Combining scores and weighting fields
  • Text search class implementation
  • Vector search and dimensionality reduction
  • BERT and transformers for embeddings
  • Practical implementation and tools for search
This workshop is part of the upcoming LLM Zoomcamp which starts on June 17. You can read more about the course on GitHub.
