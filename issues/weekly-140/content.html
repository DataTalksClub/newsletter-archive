🔧 Upcoming Workshop
In this workshop, Matt Palmer, a Developer Success Engineer at Mage, will present a demo of an end-to-end pipeline with Mage, covering:
  • Ingesting data from a streaming source
  • Performing transformations, both in Python and with dbt
  • Writing to a data source
Additionally, the presentation will discuss how Mage fits into the modern data stack and how it can be deployed to infrastructure or used for data engineering/analysis projects.

Mage is an open-source data transformation and orchestration tool designed to give your data team magical ✨ powers.

New Podcast Episode: Democratizing Causality
We uploaded a new podcast episode with Aleksander Molak, an independent machine learning researcher, author, consultant, educator and an entrepreneur.

Aleksander sees his mission in translating complex concepts into understandable bite-size pieces and sharing them with people.

We discussed:
  • Aleksander as a Causal Ambassador
  • Meta-learners vs classical ML models
  • Reducing causal bias, the super efficient estimator, and model uplifting
  • Metrics for evaluating a causal model vs a traditional ML model
  • The viability of A/B tests in causal models
  • Using causality to make decisions
  • Counterfactuals and Judea Pearl
