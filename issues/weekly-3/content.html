Events


Last week, we had our first event: Dmitry Muzalevskiy talked about deploying models with AWS SageMaker. It was quite successful and more than 70 people joined our webinar. You can find the recording on our YouTube channel.

Upcoming events:

Customer Segmentation 2.0. On November 17th, Nishant Mohan will tell us about performing customer segmentation analysis for a personalized marketing campaign. We'll cover:
  • RFM analysis
  • How can we make the most of available data?
  • How to approach a customer segmentation problem?
  • Which kind of features to analyze?
  • When to use unsupervised learning for segmentation?
  • How to analyze results and provide recommendations?

Register here.

Roles in a data team. On November 20th, Alexey Grigorev (i.e. me) will talk about different roles and responsibilities in a data team. The format of this event is different from the others: there will be no slides, just a discussion. Bring your own questions! 

Register here.

Fighting Fraud with Triplet Loss. On November 24th, Artemii Frolov will tell us about detecting modified images using Siamese networks with triplet loss. We'll talk about:

  • How fraudsters modify images
  • Embeddings, which help find distances so we can distinguish images from each other faster
  • Siamese Network with Triplet Loss explained in simple language
  • Tricks and Hacks — so we can train network better
