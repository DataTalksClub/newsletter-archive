Open-source data reliability: Soda Core GA release 
Soda Core is now generally available!

Soda is the open-source framework to test and monitor your data pipelines:
  • Declare data quality checks as human-readable code
  • Monitor your data pipelines end-to-end from ingestion to transformation and production
  • Easy to set-up, read, and maintain
Try Soda Core to maintain reliable pipelines, deliver high-quality data products and stop firefighting data issues.
