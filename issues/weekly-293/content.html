AI Engineering Buildcamp: From RAG to Agents

Building an LLM prototype is usually the easy part. AI Engineering Buildcamp focuses on what comes next: adding tools, testing the system, monitoring it, and turning it into a complete application.

During the course, you learn how to:

  • Move from a RAG pipeline to an agent that can use tools and take actions
  • Compare prompts, models, and chunking strategies using evaluation data
  • Track costs, token usage, and application behavior in real time
  • Add guardrails and tests to catch problems before users do
  • Turn these pieces into a capstone project you can show in your portfolio

Live workshop: Building AI Agent Workflows
AI agents work great when they can do focused work, but they become harder to use when people and several agents need to work on the same task. The context gets split across chat, terminal sessions, dashboards, and other places.

On September 15, Louis Amaudruz will run a hands-on workshop on building multi-agent workflow. He will show how to:
  • Define a real workflow where people and agents collaborate
  • Bring existing agents into a shared room
  • Build the workflow
  • Keep context and history visible as people and agents join, leave, and hand off tasks
  • Keep human review and approval in the loop
