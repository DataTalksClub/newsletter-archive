Project of the Week

The project of the week is a study group where we focus on building things and learning by doing.

Every day we have a set of tasks. We finish them together and hold each other accountable.

Starting on March 8, we will learn about Julia.
  1. Install the Julia programming language, do the “Hello world” exercise
  2. Go through the Basics section of the course Introduction to Julia
  3. Learn how to read input from users in Julia and work on your first project
  4. Learn about the Control flow
  5. Learn about Packages and Plotting
  6. Continue exploring more about this topic using optional tasks
Special kudos to Liliana Badillo, who organized and prepared content for the project!

Book of the Week

Ask your questions actively on our Slack community and get one of the five free copies of the book!

📕 The book of this week is GPT-3 by Sandra Kublik, Shubham Saboo
This book provides a comprehensive guide on utilizing the OpenAI API, exploring imaginative methods for your specific needs and showcasing successful businesses established through its use with GPT-3.

The book is divided into two sections covering the fundamentals of the OpenAI API and the dynamic environment around GPT-3
To participate:
  • Go to #book-of-the-week channel
  • Ask as many questions as you’d like
