Project of the Week
Are you tired of learning data science theory without any practice?

Starting from October 18, we will learn Docker.
  1. Install Docker Desktop, read the Introduction of Docker Documentation
  2. Learn basic Docker commands and test them
  3. Choose a topic and data for your project
  4. Create an API for your project
  5. Create a Dockerfile that contains commands to run the API. Run the container and test your API endpoint.
  6. Finish building your image, publish your Docker Image to DockerHub
  7. Continue exploring more about Docker, configure CI/CD on your project
Special kudos to Antonis Stellas, who organized and created content for the project!

Join us to practice together, build your network, and enjoy the learning process!
