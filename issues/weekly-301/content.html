New Free Course: 2026 Cohort Registration is Open

When an agent's tools are GPU jobs, you have to handle async calls, polling, retries, resuming, and duplicate execution. This free course shows you how to:

  • Run image, video, and audio models on serverless GPUs, without managing a cluster

  • Give agents GPU models as tools (MCP) and build generate, evaluate, regenerate loops

  • Fan out batch workloads, handle failures, and report cost per asset


To apply, tell us what you're building. We'll select a limited number of participants who'll join the live cohort with homework and a final project. The materials are public and MIT-licensed, so you can still follow along.
