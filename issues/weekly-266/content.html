Stream Processing with PyFlink
Streaming introduces new challenges: late events, out-of-order data, state management, and failure recovery. This workshop focuses on how to handle them correctly using modern best practices.

We'll produce mock event data into Redpanda, process it with real-time windowed aggregations in Flink, and sink results into PostgreSQL for immediate analysis.

You'll learn how to:
  • Understand when to use continuous streaming vs. micro-batching
  • Set up a practical streaming stack with Redpanda, Flink, and Postgres
  • Work with watermarks and windowing to handle delayed and unordered events
  • Configure checkpointing for resiliency and recovery
  • Use the PyFlink Table API to write SQL-like transformations in Python
This is a live demo session in a fully working environment, including practical troubleshooting tips and discussion of common Flink pitfalls.
