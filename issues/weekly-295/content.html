How Conductrics Builds Predictive Audiences from Real-Time Snowplow Data

A model can only guess right if it has good data while someone is still on the page. Snowplow delivers behavioral data in real time, and Snowplow Signals computes and serves profile attributes as people use your product, so the prediction is based on what someone is doing now, not what they did last week.

  • What a model can do with a full behavioral event stream and live attributes, instead of page views and a conversion flag
  • How Condutrics finds its audiences, and what you can constrain: how many, how much evidence it needs, which version runs
  • What lands back in Snowplow, so the results sit alongside everything else you measure

From Alexey on Data: Jev AI

Do you need a full LLM call to decide which agent should handle a request?

In his new newsletter, Alexey tries Jev from TypeSafe AI, a model built for fast decisions instead of text generation. He replaces a GPT-4o-mini router with Jev and compares the two on 50 hand-labeled requests.

Both routers got every case right, but Jev was 2.4x faster and 3.4x cheaper. If you use an LLM for routing, guardrails, or other quick yes/no decisions, the article shows what switching looks like in practice.
