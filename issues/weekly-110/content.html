🔧 Workshop

22 Feb 2023, Maximizing Confidence in Your Data Model Changes with dbt and PipeRider
 

In this hands-on workshop, we’ll use PipeRider with a dbt project to show the benefit of data profiling for data pipelines.

We will cover the following steps:

  • Discuss the importance of data profiling as a method of ‘code review’ for data projects
  • Add PipeRider to an existing dbt project
  • Create a new PR branch and change some models
  • Generate data profile reports and comparison reports
  • Post the data profile comparison to the data project pull request comment
  • Upload data profile reports to PipeRider Cloud for sharing
  • Automate dbt and PipeRider with CI (GitHub Actions)
