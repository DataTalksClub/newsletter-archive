Open-Source Spotlight: LangWatch Scenarios
This episode of the Open-Source Spotlight highlights Scenario, an agent testing framework built for simulating real-world user interactions and edge cases.

Scenario allows you to test AI agent behavior through simulation, evaluate conversations at any point, and integrate easily with any LLM eval framework. It’s designed to be agnostic and lightweight, available in Python, TypeScript, and Go.

Join us for a demo with Rogerio, where you will learn about:
  • The origin of Scenario and the challenge of testing non-deterministic agents
  • How Scenario simulates users and edge cases
  • A walkthrough of testing a recipe-generating agent
  • How to build and test a lovable clone agent
  • Using tools and mocks to simulate multi-turn interactions
  • Scenario’s approach to efficiency, cost, and future plans
  • Advice for working with and testing AI agents
See you there!
