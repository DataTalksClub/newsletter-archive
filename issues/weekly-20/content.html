Conference

ML REPA Week 2021 program is 90% ready! The main focus of the conference is machine learning in production:

  • Topic 1: Machine Learning project and teamwork organization
  • Topic 2: ML pipelines automation. Code and Data version control. Reproducibility
  • Topic 3: ML experiments management and metrics tracking. Model Lifecycle Management
  • Topic 4: CI/CD and MLOps in ML. Testing in ML
  • Topic 5: Testing and Monitoring in Machine Learning
Save the date: it's from 5 to 11 April 2021. More than 30 talks and tutorials - online and free! Register here.
