New Podcast on Data Access Management
We chatted live with Bart Vandekerckhove, a co-founder and CEO at Raito.

Bart wants to help data teams save time on data access management, so they can focus on innovation. As the former PM of Privacy at Collibra, Bart has seen firsthand how slow data access management processes can harm innovation.

We discussed:

Data governance
  • What is data governance?
  • How to learn about data governance?
  • What skills are needed to do data governance effectively?
  • When does an organization need to start thinking about data governance?
Data access management
  • Good data access management processes
  • The importance of automating data access
  • How data access management works with a data mesh approach
