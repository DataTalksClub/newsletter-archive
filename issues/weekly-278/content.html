LLM Zoomcamp Workshops
  • From RAG to AI Agents: Learn how function calling and tool use extend a basic RAG system. We’ll show how LLMs can work with external tools, APIs, and structured actions.
  • RAG and Agents Evaluation: Learn how to evaluate both retrieval quality and LLM-generated answers in RAG and agentic systems. We’ll cover practical ways to measure whether your system finds the right context and produces useful responses.
  • Monitoring LLM Applications: Learn how to monitor LLM applications after they are deployed. We’ll cover traces, user feedback, and production signals that help you understand quality issues and improve the system.
  • LLM Zoomcamp 2026 Course Launch: Join the launch session for LLM Zoomcamp 2026. We’ll walk through the course structure, what you’ll build, how the assignments work, and how to get the most out of the course.

Tutorial on Building an Agent with Guardrails

Alexey is doing a workshop on "Building an Agent with Guardrails" tomorrow using Python, Pydantic, minsearch, and the plain OpenAI Python SDK.

The materials are already published as a written tutorial that you can check out for free.

With this workshop, you'll learn building:

  • A RAG baseline with a keyword search
  • A framework-neutral agent loop with one search tool
  • Input checks for topic and intent
  • Output checks for unsafe promises or policy violations
  • Multiple guardrails with clear responsibilities
  • Concurrent guardrail checks that keep latency low
