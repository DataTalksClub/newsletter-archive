MLOps Zoomcamp

We almost finished the best practices section and it's time to start working on the project! 

In the project, you'll get to use everything you learned so far. For that, you will need:

  • Select a dataset that you're interested in (see datasets.md)
  • Train a model on that dataset tracking your experiments
  • Create a model training pipeline
  • Deploy the model in batch, web service or streaming
  • Monitor the performance of your model
  • Follow the best practices
