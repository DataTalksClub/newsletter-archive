Machine Learning Zoomcamp

Last week, we announced the Kaggle competition.

Timur Kamaliev, our teaching assistant, prepared a getting-started notebook for the competition using BERT (Bidirectional Encoder Representations from Transformers) language model.

  • It creates vector representations of questions and answers using BERT model
  • For each question and answer candidate, it calculates the cosine similarity between vectors and then selects the best candidate as the final answer
