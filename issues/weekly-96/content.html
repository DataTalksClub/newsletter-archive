dstack – “Terraform for machine learning”
dstack is a lightweight utility that lets you run ML workflows in a configured AWS account via the command line.
  • Provisions required resources (and tears down afterward)
  • Sets up the environment (incl. CUDA, Conda, and Python)
  • Saves output artifacts 
The utility is open-source and free!
Give it a star on GitHub!

Machine Learning Zoomcamp: Production-Ready Machine Learning

This week, we'll learn about BentoML - a tool for deploying production-ready ML services:

  • Saving and loading your models with BentoML
  • Serving the model with BentoML
  • Validating data with Pydantic
  • Load-testing the service with pylocust
  • Making the service faster with async io and batching
  • Deploying it with AWS ECS
  • And deploying the Stable Diffusion model with BentoML
This is a new module: we didn't have it in our previous iteration of ML Zoomcamp. And even if you're not taking the course, you'll find the materials very useful.

Check it out!
